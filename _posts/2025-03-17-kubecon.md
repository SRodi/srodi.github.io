```mermaid
%%{init: {'sequence': {'mirrorActors': false}, 'themeVariables': {'messageFontSize': '36px', 'noteFontSize': '36px', 'actorFontSize': '36px'}}}%%
sequenceDiagram
    participant K as Kubelet
    participant CR as Container Runtime
    participant C as CNI Plugin
    participant P as Pod Network

    K->>CR: 1. Create Pod Sandbox
    rect rgba(255, 0, 0, 0.1)
    CR->>P: 2. Create netns (pause container)
    end
    CR->>C: 3. Call CNI ADD
    activate C
    rect rgba(255, 0, 0, 0.1)
    C->>P: 4a. Create veth pair
    C->>P: 4b. Assign IP address (via IPAM)
    C->>P: 4c. Setup routes
    end
    C-->>CR: 5. Return success
    deactivate C
    CR-->>K: 6. Sandbox ready
    Note over K,CR: pod has IP before containers start
    K->>CR: 7. Start containers (share netns)
```

## Demo Architecture

To make this tangible, let's visualize the environment we are debugging.

We have a 2-node cluster. Each node runs `kube-proxy`, and we have a central `coredns` service. We have two application workloads: **Pod A** (Client) on Node 1 and **Pod B** (Server) on Node 2. Both are exposed via Services.

```mermaid
graph TB
    subgraph K8s ["Kubernetes Cluster"]
        subgraph ControlPlane ["Control Plane Node"]
            direction TB
            Etcd["etcd (Store)"]
            ApiServer["API Server"]
            KCM["Controller Manager<br>(EndpointSlice Controller)"]
            
            subgraph Resources ["Service Discovery Resources"]
                SvcA["Service A<br>10.96.1.1"]
                EpA["EndpointSlice A"]
                
                SvcB["Service B<br>10.96.2.2"]
                EpB["EndpointSlice B"]
                
                KubeDNS["kube-dns<br>10.96.0.10"]
                EpDNS["EndpointSlice DNS"]
            end
        end

        subgraph Node1 ["Node 1 (10.0.0.10)"]
            KubeProxy1["kube-proxy"]
            Rules1["iptables/IPVS Rules"]
            
            subgraph DNSLogic ["DNS"]
                CoreDNS["coredns Pod<br>10.244.0.3"]
                DNSRecords["DNS Records<br>svc-a.default -> 10.96.1.1"]
            end

            PodA["Pod A (Client)<br>10.244.1.5"]
        end

        subgraph Node2 ["Node 2 (10.0.0.11)"]
            KubeProxy2["kube-proxy"]
            Rules2["iptables/IPVS Rules"]
            PodB["Pod B (Server)<br>10.244.2.8"]
        end

        %% Control Plane Logic
        Etcd <--> ApiServer
        ApiServer <--> KCM
        KCM -.->|Creates & Syncs| Resources

        %% Proxy Watches (Data Plane)
        KubeProxy1 -.->|Watches| ApiServer
        KubeProxy1 -->|Writes| Rules1
        
        KubeProxy2 -.->|Watches| ApiServer
        KubeProxy2 -->|Writes| Rules2

        %% Resource Linking (Logical)
        SvcA -.->|Selector| EpA 
        EpA -.->|Target| PodA
        
        SvcB -.->|Selector| EpB
        EpB -.->|Target| PodB
        
        KubeDNS -.->|Selector| EpDNS
        EpDNS -.->|Target| CoreDNS
    end
```
